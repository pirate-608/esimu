# ZJU Simplified World

This is a compact ZJUers Simulator adaptation for generated esimu projects.
It uses neutral `forum` and `messenger` protocol IDs and has no runtime
dependency on the ZJUers Simulator repository.

The default theme intentionally stays small:

- one two-semester major;
- one local event and two forum posts;
- three message contacts;
- two items and two achievements;
- failure and graduation ending branches.
